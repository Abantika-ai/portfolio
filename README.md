# portfolio

Personal portfolio site for Abantika Ghosh, PhD candidate in experimental
astroparticle physics working on the LZ (LUX-ZEPLIN) dark matter
direct-detection experiment.

Built with React + Vite. Physics-themed design: an animated canvas hero
("drift chamber" particle simulation modeled on the S1/S2 signal
mechanism in a liquid-xenon TPC), a day/night (light/dark) theme toggle,
and sections for research, PhD timeline, skills, and publications.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Editing content

All copy (name, bio, research, timeline, publications, links) lives in
[`src/data/content.js`](src/data/content.js) — components don't need to
change when the content does.
